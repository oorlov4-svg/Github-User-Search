# Github-User-Search

### Projektbeschreibung

**GitHub User Search** ist eine einfache Webanwendung, mit der Benutzer nach GitHub-Profilen suchen können. Die Anwendung nutzt die GitHub API, um Informationen wie Profilbild, Benutzername, Biografie, Anzahl der Repositories, Follower und Following in Echtzeit abzurufen und übersichtlich darzustellen.

**Verwendete Technologien:**

* HTML5
* CSS3
* JavaScript (ES6)
* GitHub REST API

**Funktionen:**

* 🔍 Suche nach GitHub-Benutzern
* 👤 Anzeige von Profilbild und Benutzerinformationen
* 📦 Anzeige der öffentlichen Repositories
* 👥 Anzeige von Followern und Following
* 📱 Responsives Design für Desktop und Mobilgeräte
* ⚡ Echtzeit-Daten über die GitHub API
